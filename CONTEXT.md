# My Cheap Chef — «Готовь из скидок»

## О проекте

Приложение помогает людям экономить деньги, предлагая рецепты из продуктов, которые сейчас по скидке в супермаркетах (Lidl, Kaufland — Словакия).

## Архитектура (monorepo)

```
my-cheap-chef/
├── src/
│   ├── app/              ← Next.js App Router (клиентские страницы)
│   │   └── api/          ← API routes (серверная логика, Route Handlers)
│   ├── lib/              ← Общие типы, утилиты, константы
│   └── components/       ← (будущее) React-компоненты
├── scripts/              ← Cron-скрипты (парсинг каталогов, генерация рецептов)
├── data/                 ← JSON-файлы с данными (products, recipes, catalog-images)
├── public/               ← Статические ассеты
└── 🧠 Идея приложения.md ← Описание идеи и бизнес-логики
```

## Стек технологий

- **Frontend**: Next.js 16, React 19, CSS Modules
- **Backend**: Next.js API Routes (Route Handlers)
- **Scripts**: TypeScript (tsx), запуск по крону
- **AI**: Vision AI (парсинг каталогов) + Text AI (генерация рецептов) — провайдер TBD
- **Данные**: JSON-файлы (MVP), в будущем PostgreSQL/SQLite
- **Деплой**: Vercel (планируется)

## Ключевые команды

```bash
npm run dev             # запуск dev-сервера
npm run build           # сборка
npm run data:parse      # парсинг продуктов через Lidl API
npm run catalog:ingest  # (будущее) парсинг картинок каталога через Vision AI
npm run recipe:generate # (будущее) генерация рецептов через AI
```

## Поток данных

1. **Суббота ночью**: скрипт парсит картинки каталога → `data/products.json`
2. **После парсинга**: скрипт генерирует рецепты → `data/recipe.json`
3. **Клиент**: читает JSON → показывает продукты + рецепт недели
4. **Платная функция** (будущее): генерация дополнительных рецептов по запросу
