# Catalog Images

Сюда загружаются картинки каталогов для обработки Vision AI.

## Структура

```
catalog-images/
└── lidl/
    └── YYYY-MM-DD/     ← дата начала действия каталога
        ├── page-01.jpg
        ├── page-02.jpg
        └── ...
```

## Заметки

- Папка добавлена в .gitignore (картинки тяжёлые)
- Загружаются вручную (MVP) или автоматически (будущее)
- Обычно достаточно 3-5 первых страниц каталога
