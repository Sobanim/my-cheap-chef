# src/app/api/

## Purpose

API routes — the app's server logic (Next.js Route Handlers).

## What's here / coming

- `recipe/route.ts` — endpoint to fetch the pre-generated recipe of the week from `data/recipe.json`
- `generate-recipe/route.ts` — (future) generate additional recipes via AI (future paywall)

> Products are **not** served through an API route: pages read them directly from `src/lib/services/lidlService.ts` (live Lidl API). The old `products/route.ts` route was removed as unused.

## Principles

- API routes read data from `data/` (JSON files) generated by cron scripts
- Heavy operations (catalog parsing, recipe generation) run NOT here, but in `scripts/` via cron
- API routes only serve ready data to the client (fast, no delays)
- In the future: payment verification before generating personalized recipes

## Technologies

- Next.js Route Handlers (GET, POST)
- In the future: Stripe for payment verification
