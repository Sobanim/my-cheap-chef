# src/app/api/

## Назначение

API routes — серверная логика приложения (Next.js Route Handlers).

## Что здесь будет

- `generate-recipe/route.ts` — эндпоинт для генерации дополнительных рецептов через AI (будущий paywall)
- `products/route.ts` — эндпоинт для получения текущих продуктов по скидке
- `recipe/route.ts` — эндпоинт для получения предгенерированного рецепта недели

## Принципы

- API routes читают данные из `data/` (JSON-файлы)
- Тяжёлые операции (парсинг каталогов, генерация рецептов) выполняются НЕ здесь, а в `scripts/` по крону
- API routes только отдают готовые данные клиенту (быстро, без задержек)
- В будущем: проверка оплаты перед генерацией персональных рецептов

## Технологии

- Next.js Route Handlers (GET, POST)
- В будущем: Stripe для проверки платежей
